# 📁 Project

# 🏠 House Price Prediction Using Machine Learning

## Project Description

This project predicts residential house prices using the **Kaggle House Prices – Advanced Regression Techniques** dataset.

The dataset contains both numerical and categorical features such as lot area, overall quality, garage capacity, number of rooms, neighborhood, and other property characteristics.

Using Python and Machine Learning techniques, the dataset was cleaned, preprocessed, transformed, and used to train an **XGBoost Regression** model capable of accurately estimating house prices for unseen properties.

---

## 🎯 Project Objectives

- Build an accurate house price prediction model
- Perform data preprocessing and cleaning
- Handle missing values
- Apply feature engineering techniques
- Encode categorical variables
- Normalize numerical features
- Train an XGBoost Regression model
- Evaluate model performance
- Analyze feature importance
- Generate predictions for unseen data

---

## 💡 Key Insights

- Built a high-performing regression model using XGBoost.
- Achieved an **R² Score of 0.9069** on the validation dataset.
- Achieved an **RMSE of approximately \$23,000**.
- Obtained a **Kaggle RMSLE score of 0.14774**.
- Identified the most influential features affecting house prices.
- Developed a complete end-to-end machine learning pipeline suitable for real-world prediction tasks.

# 📊 Dataset Overview

The project uses the **House Prices – Advanced Regression Techniques** dataset available on Kaggle.

### Dataset Files

- train.csv
- test.csv
- sample_submission.csv

### Important Features

- Lot Area
- Overall Quality
- Ground Living Area
- Garage Capacity
- Basement Quality
- Year Built
- Neighborhood
- House Style
- Exterior Quality
- Sale Price (Target Variable)

---

# 🔄 Data Preprocessing

The dataset was preprocessed using the following techniques:

- Handling missing values
- Mean imputation for numerical features
- Mode imputation for categorical features
- One-Hot Encoding
- Feature Scaling using MinMaxScaler
- Log Transformation of the target variable
- Train-Test Split (80:20)

---

# 📈 Model Used

### XGBoost Regression

The project uses the **XGBoost Regressor**, a powerful Gradient Boosting algorithm known for its high accuracy, speed, and ability to model complex relationships within structured datasets.
